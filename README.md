# attendance-management-system
Web-Based Attendance Management System
This system is designed to simplify attendance collection and record-keeping in academic environments. Built with a PHP backend and MySQL relational database, it provides dedicated workflows for both students (self-check-in) and faculty (records management, analytics, and CSV exporting).
# Access the interface here
 https://srathira.github.io/attendance-management-system/

# Key Technical Features:
Centralized Dashboard: Real-time metrics showing overall attendance rates, class sizes, and attendance warnings.

Multi-Role Access Simulation: Separate interfaces for students to log attendance and faculty to review/update historical records.

Data Portability: Capabilities to export attendance sheets directly to spreadsheet-compatible formats.
